## Arquitetura do Sistema

### Estrutura de Sincronização
```
1. VAGAS (independente)
   ↓
2. POSIÇÕES (requer vagaId)
   ↓
3. CANDIDATURAS (requer vagaId, fornece talentIds)
   ↓
4. TALENTOS (otimizado com talentIds das candidaturas)
```

### Arquivos Principais

#### Scripts de Execução
- `run_sync.py` - Script principal de sincronização
- `scheduler.py` - Agendamento automático
- `API_Inhire.py` - Cliente API legado

#### Modelos
- `models/database.py` - Modelos SQLAlchemy (tabelas PostgreSQL)
- `models/api_schemas.py` - Schemas Pydantic (validação API)

#### Serviços
- `services/auth_service.py` - Autenticação JWT com renovação
- `services/api_client.py` - Cliente HTTP para API InHire
- `services/database_service.py` - Operações de banco (UPSERT)
- `services/sync_service.py` - Orquestrador de sincronização

#### Scripts de Manutenção
- `scripts/maintenance/fix_candidatura_enum.py` - Corrige enum declined
- `scripts/maintenance/fix_stuck_sync.py` - Corrige syncs travadas (>30min)
- `scripts/maintenance/force_fix_stuck_sync.py` - Força correção de todas

#### Scripts de Utilidades

## Consultas SQL Úteis

### Status das Candidaturas
```sql
SELECT status, COUNT(*) as total
FROM candidaturas
GROUP BY status
ORDER BY total DESC;
```

### Últimas Sincronizações
```sql
SELECT
    sync_type,
    sync_entity,
    status,
    start_time,
    records_processed,
    records_created,
    records_failed
FROM sync_log
ORDER BY start_time DESC
LIMIT 10;
```

### Candidaturas sem Talento
```sql
SELECT COUNT(*)
FROM candidaturas c
LEFT JOIN talentos t ON c.talent_inhire_id = t.inhire_id
WHERE t.id IS NULL;
```

### Vagas com Mais Candidaturas
```sql
SELECT
    v.name,
    v.status,
    COUNT(c.id) as total_candidaturas
FROM vagas v
LEFT JOIN candidaturas c ON c.vaga_id = v.id
GROUP BY v.id, v.name, v.status
ORDER BY total_candidaturas DESC
LIMIT 10;
```

## Notas Técnicas Importantes

### Ordem de Sincronização É CRÍTICA
```
NUNCA alterar a ordem: Vagas → Posições → Candidaturas → Talentos
Posições e Candidaturas dependem de Vagas existirem no banco!
```

### Normalização de Datetime
```python
# SEMPRE usar _normalize_datetime() ao salvar no banco
updated_at_inhire = self._normalize_datetime(vaga_api.updatedAt)
```

### Status das Candidaturas
```python
# API retorna UPPERCASE, banco espera lowercase
status_normalized = cand_api.status.lower() if cand_api.status else None
```
